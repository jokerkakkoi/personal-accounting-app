# P-01 欢迎页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-01 |
| 页面名称 | 欢迎页（首次启动引导） |
| 所属模块 | 用户引导 |
| 入口 | 首次安装启动应用 |
| 出口 | 引导完成后进入首页（P-02） |

## 目的与定位

- 向首次安装的用户简要介绍应用核心价值。
- 让用户在 1-2 步内完成引导并立即开始记账。
- 不收集任何账号信息（无注册登录流程），符合"打开即用"的设计原则。

## 用户故事

- **PRD 关联**：与"用户引导（简单欢迎页面 1-2 页）"相关。
- 作为新用户，我希望快速了解应用能做什么，以便决定是否继续使用。
- 作为新用户，我希望无需注册登录即可使用，以便保护隐私并立即上手。

## 页面元素

### 第 1 屏：产品介绍

- **顶部**：应用 Logo + 应用名称"个人记账"
- **中部**：插图（温暖奶油色背景 + 珊瑚色元素，体现 CLAUDE-DESIGN 风格）
  - 文案标题：`简单、智能、本地化`
  - 文案副标题：`数据完全本地存储，AI 智能分类，守护你的隐私`
- **底部**：
  - 进度指示器（第 1 屏 / 共 2 屏）
  - 主按钮：`下一步`
  - 次要文字按钮：`跳过`

### 第 2 屏：功能亮点

- **中部**：3 个亮点卡片（垂直堆叠或横向滑动）
  - 卡片 1：`📒 轻松记账` — 一键记录收支
  - 卡片 2：`🤖 AI 智能分类` — 自动归类（可在设置中配置 API）
  - 卡片 3：`📊 预算与报表` — 掌控财务状况
- **底部**：
  - 进度指示器（第 2 屏 / 共 2 屏）
  - 主按钮：`开始使用`
  - 次要文字按钮：`跳过`

## 交互流程

1. 用户首次启动应用，检测到本地无任何数据时进入欢迎页。
2. 第 1 屏：用户可点击 `下一步` 进入第 2 屏，或点击 `跳过` 直接进入首页。
3. 第 2 屏：用户可点击 `开始使用` 进入首页，或点击 `跳过` 直接进入首页。
4. 任意时刻点击 `跳过`，都将标记"已展示欢迎页"，下次启动不再显示。
5. 进入首页后，触发首次进入空状态引导（"还没有交易，点击 + 添加"）。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 用户从设置中"清除数据" | 不重新显示欢迎页（清除数据不等于重装），避免给老用户造成干扰 |
| 应用版本升级 | 保持已展示标志，不重新显示 |
| 网络状态 | 欢迎页不依赖网络，所有内容为本地静态资源 |

## 设计要点

- **风格**：温暖奶油色画布（#FAF7F2 类），珊瑚色强调色（#FF7F50 类），遵循 CLAUDE-DESIGN 风格。
- **插图**：使用扁平化插画风格，避免复杂图形。
- **动画**：屏间切换使用淡入淡出 / 横向滑动，时长 250ms。
- **按钮**：主按钮使用珊瑚色实心，次要文字按钮使用低对比度灰色。
- **可访问性**：按钮点击区域不小于 44×44pt。

## 相关模块

- **进入**：应用启动判断
- **离开**：首页（P-02）

## 验收标准

- [ ] 首次安装启动应用时显示欢迎页。
- [ ] 点击 `跳过` 或完成引导后进入首页，且后续启动不再显示欢迎页。
- [ ] 屏间切换流畅，无明显卡顿。
- [ ] 欢迎页无网络依赖，离线可正常显示。
- [ ] 视觉风格与设计系统一致（温暖奶油色 + 珊瑚色）。

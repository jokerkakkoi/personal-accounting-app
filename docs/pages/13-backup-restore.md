# P-13 备份与恢复页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-13 |
| 页面名称 | 备份与恢复页 |
| 所属模块 | 数据备份模块 |
| 入口 | 设置页（P-14）`数据备份与恢复` |
| 出口 | 返回设置页（P-14） |

## 目的与定位

- 提供数据导出（备份）功能，生成 JSON 文件。
- 提供数据导入（恢复）功能，从 JSON 文件还原数据。
- 支持选择导出日期范围。
- 导入采用全量覆盖策略，使用事务保证原子性。

## 用户故事

- **PRD 关联**：#28、#29、#30
- 作为用户，我希望将数据导出为 JSON 格式以便备份。
- 作为用户，我希望选择导出的日期范围。
- 作为用户，我希望导入之前备份的 JSON 文件以便恢复数据。

## 交互流程

### 导出数据

1. 用户选择日期范围。
2. 点击 `导出为 JSON`。
3. 前端显示加载状态。
4. Rust 层生成 JSON 文件流（含元数据）。
5. 完成后调用 Android 原生分享（Share Sheet）。
6. 用户选择保存位置 → 文件保存成功 → Toast 提示。

### 导入数据

1. 用户点击文件选择器 → Android 文件选择器打开。
2. 选择 `.json` 文件 → 前端解析并显示元数据。
3. 用户点击 `导入此备份` → 弹窗确认。
4. 确认后：
   - 弹窗显示进度（处理中，请稍候...）。
   - Rust 层开启事务 → 清空本地所有表 → 写入备份数据。
   - 成功：Toast `导入成功` + 跳转到首页。
   - 失败：回滚到导入前状态 + Toast `导入失败，已恢复原数据` + 错误详情。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| JSON 文件格式错误 | 解析失败时提示 `文件格式无效` |
| JSON 版本不兼容 | 提示 `备份文件版本不兼容（当前支持 v1.0）` |
| 导入过程中断 | 事务回滚，保留原数据 |
| 导入空数据 | 仍执行清空 + 写入空数据，需二次确认 |
| 文件过大（>10MB） | 提示 `文件过大，可能需要较长时间` |
| 选择非 JSON 文件 | 文件选择器过滤或前端校验拒绝 |
| 日期范围选择异常 | 限制：开始日期 ≤ 结束日期 |
| 网络断开 | 不影响（完全本地操作） |

- **导出按钮**：主按钮（珊瑚色实心），宽度撑满。
- **导入按钮**：危险按钮（红色实心），需二次确认。
- **警告横幅**：红色背景（#FFE5E5），图标 + 文案。
- **文件元数据卡片**：白底圆角，显示版本、时间、笔数。
- **进度展示**：模态弹窗 + 进度条 + 文字提示。
- **配色**：
  - 导出：珊瑚色（积极操作）
  - 导入：红色（危险操作）
  - 警告：黄色或红色

# P-05 交易搜索页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-05 |
| 页面名称 | 交易搜索页 |
| 所属模块 | 交易模块 |
| 入口 | 首页顶部搜索图标 |
| 出口 | 返回首页、交易详情 P-04 |

## 目的与定位

- 帮助用户快速定位特定交易记录。
- 支持按日期、金额、描述（备注/分类名）搜索。
- 提供筛选器以缩小结果范围。

## 用户故事

- **PRD 关联**：#6
- 作为用户，我希望按日期范围搜索交易。
- 作为用户，我希望按金额范围搜索交易。
- 作为用户，我希望按描述/备注关键词搜索交易。

## 页面元素

### 顶部搜索栏

- **搜索输入框**：
  - 占位符：`搜索备注、分类...`
  - 右侧 `✕` 清除按钮
- **左侧**：返回箭头
- **右侧**：`筛选` 图标按钮

### 筛选器面板（点击筛选按钮展开）

- **日期范围**：
  - `全部时间` / `最近 7 天` / `最近 30 天` / `本月` / `自定义`
  - 自定义时弹出日期范围选择器
- **金额范围**：
  - `不限` / `0-100` / `100-500` / `500-2000` / `2000+` / `自定义`
- **类型**：
  - `全部` / `支出` / `收入`
- **分类多选**：
  - 网格显示所有分类，可多选
- **应用 / 重置按钮**：
  - `重置` 清空所有筛选
  - `应用` 关闭面板并应用筛选

### 结果列表

- 与首页列表项一致（分类图标 + 名称 + 备注 + 金额）
- 结果按日期降序分组
- 列表顶部显示 `共找到 X 条结果`
- 空结果状态：`没有找到符合条件的交易`

## 交互流程

1. 用户从首页点击搜索图标 → 进入搜索页。
2. 在搜索框输入关键词 → 实时筛选（前端 debounce 300ms）。
3. 点击 `筛选` → 展开筛选面板 → 选择条件 → 点击 `应用`。
4. 列表实时更新结果。
5. 点击某条结果 → 进入交易详情页（P-04）。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 搜索关键词为空 | 显示所有交易（受筛选条件约束） |
| 无匹配结果 | 显示空状态 `没有找到符合条件的交易` |
| 仅输入特殊字符 | 视为普通字符处理，不抛错 |
| 自定义日期范围超出 | 限制：开始日期 ≤ 结束日期 |
| 搜索性能 | SQLite 索引 + 关键词分词，结果超过 30 条时分页 |

## 相关模块

- **离开**：交易详情（P-04）、首页（P-02）

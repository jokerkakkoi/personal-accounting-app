# P-12 AI 智能设置页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-12 |
| 页面名称 | AI 智能设置页 |
| 所属模块 | AI 分类模块 |
| 入口 | 设置页（P-14）`AI 智能分类` |
| 出口 | 返回设置页（P-14） |

## 目的与定位

- 让用户配置 LLM API 密钥及相关参数。
- 加密存储 API 密钥到 Android KeyStore。
- 提供启用 / 禁用 AI 分类的开关。
- 允许用户测试 API 连通性。

## 用户故事

- **PRD 关联**：#25、#27
- 作为用户，我希望自己配置 LLM API 密钥以便保护隐私。
- 作为用户，我希望 AI 异步分类并可修改。
- 作为用户，我希望离线时 AI 降级到未分类。

## 页面元素

### 顶部应用栏

- **左侧**：返回箭头
- **标题**：`AI 智能分类`

### 启用开关

- **总开关**：`启用 AI 智能分类`
- 关闭时隐藏下方配置项
- 默认关闭

### API 配置

- **API Base URL** 输入框
  - 占位符：`https://api.openai.com/v1`
  - 必填
- **API Key** 输入框
  - 类型：密码（隐藏显示）
  - 右侧眼睛图标切换显示
  - 必填
- **模型选择**：
  - 下拉框，预设常用模型（`gpt-3.5-turbo`、`gpt-4` 等）
  - 支持自定义输入
- **超时时间**：滑块或输入框，默认 10 秒

### 高级设置

- **Prompt 模板**（可选）：
  - 多行文本输入框
  - 默认：`从以下分类列表中选一个最匹配的分类返回，仅返回分类名称，不要额外文字。分类列表：[...]`
  - 允许用户自定义

### 操作按钮

- **测试连接** 按钮：发送一次测试请求验证配置
- **保存** 按钮：保存配置
- **清除配置** 按钮：删除已保存的 API Key（次要操作）

### 状态提示

- **API Key 状态**：`未配置` / `已配置（加密保存）`
- **测试结果**：
  - 成功：绿色提示 `连接成功`
  - 失败：红色提示 + 错误详情

## 交互流程

### 配置 API

1. 用户打开启用开关。
2. 填写 API Base URL 和 API Key。
3. 选择模型。
4. 可选：调整超时时间或 Prompt 模板。
5. 点击 `保存` → 加密存储到 Android KeyStore → 提示 `保存成功`。

### 测试连接

1. 用户点击 `测试连接` 按钮。
2. 发送一次轻量测试请求（最小 token）。
3. 显示加载状态。
4. 返回结果：
   - 成功：绿色 `连接成功` 提示。
   - 失败：红色 `连接失败` + 错误详情（如 `401 Unauthorized`）。

### 修改配置

1. 用户修改任意字段。
2. 点击 `保存` → 重新加密存储。

### 清除配置

1. 用户点击 `清除配置` → 弹窗确认 `确定要清除 API 配置吗？清除后将无法使用 AI 分类`。
2. 确认后清除 KeyStore 中的密钥。
3. 开关自动关闭。

### 离线行为

- 保存交易时检测网络状态。
- 离线时不调用 AI 分类，分类标记为 `未分类`。
- 在线但 API 失败/超时时也降级为 `未分类`。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| KeyStore 加密失败 | 提示 `保存失败，请重试` |
| API Key 为空 | `保存` 按钮置灰 |
| API Key 格式异常 | 不做强制校验，由后端测试时反馈 |
| 测试连接超时 | 提示 `连接超时，请检查网络或 API 地址` |
| 网络断开 | 测试按钮显示 `当前无网络` |
| 用户清除配置后重新打开页面 | 显示空表单 |

## 设计要点

- **API Key 输入**：使用密码类型，右侧眼睛图标切换。
- **开关**：使用珊瑚色激活态，与设计系统一致。
- **测试按钮**：次要按钮样式（描边），不喧宾夺主。
- **保存按钮**：主要按钮样式（实心珊瑚色）。
- **状态颜色**：
  - 已配置：绿色
  - 未配置：灰色
  - 错误：红色
- **安全说明**：页面顶部添加说明 `API Key 将加密保存在本机，不会上传到任何服务器`，缓解用户隐私顾虑。

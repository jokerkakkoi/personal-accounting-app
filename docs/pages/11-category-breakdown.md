# P-11 分类支出明细页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-11 |
| 页面名称 | 分类支出明细页 |
| 所属模块 | 报表分析模块 |
| 入口 | 报表分析页（P-09）`分类支出明细` 入口 |
| 出口 | 返回报表分析页（P-09）、搜索页（P-05，传入分类参数直达） |

## 目的与定位

- 通过饼图直观展示各分类支出的占比。
- 列表形式展示各分类的金额、笔数、平均值。
- 帮助用户了解"钱花在哪里"。

## 用户故事

- **PRD 关联**：#23
- 作为用户，我希望查看分类支出明细饼图。
- 作为用户，我希望知道我的钱花在哪里。

## 页面元素

### 顶部应用栏

- **左侧**：返回箭头
- **标题**：`分类支出明细`

### 时间范围选择

- **分段控制器**：`本月` / `上月` / `近 3 个月` / `近 12 个月` / `自定义`
- 自定义时弹出日期范围选择器
- 默认 `本月`

### 饼图区

- **环形饼图**（ECharts）：
  - 每个扇区代表一个分类
  - 颜色：使用分类对应的主题色
  - 中心显示总支出金额 `¥ 8,765.00`
  - 图例：右侧或下方，分类名 + 占比百分比
- **交互**：点击扇区高亮 + 列表对应项滚动到视野中

### 分类列表

- **列表项**：
  - 左侧：分类图标（圆形背景）+ 名称
  - 中部：金额 + 占比
  - 右侧：笔数 + 平均值
- **排序**：按金额降序
- **汇总行**：底部 `合计 ¥8,765.00 · 30 笔`

## 交互流程

1. 用户从报表分析页点击 `分类支出明细` 入口 → 进入分类支出明细页。
2. 默认展示本月分类支出。
3. 切换时间范围 → 饼图和列表刷新。
4. 点击饼图扇区 → 列表对应项高亮。
5. 点击列表项 → 跳转到搜索页（P-05），并预填该分类筛选条件，列表展示该分类下所有交易。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 选中时间段无支出 | 饼图区域显示 `暂无数据` |
| 分类过多（>20） | 仅显示前 10 个分类 + `其他` 汇总项 |
| 分类被删除 | 该分类支出归入 `已删除分类` 灰色扇区 |
| 比例极小（<1%） | 合并到 `其他` 项 |

## 相关模块

- **进入**：报表分析页（P-09）
- **离开**：返回报表分析页（P-09）、搜索页（P-05，传入分类参数直达）

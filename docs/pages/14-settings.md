# P-14 设置页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-14 |
| 页面名称 | 设置页（我的） |
| 所属模块 | 设置模块 |
| 入口 | 底部 Tab `我的` |
| 出口 | AI 设置 P-12、备份与恢复 P-13、分类管理 P-06、欢迎页 P-01（清除数据后不重定向） |

## 目的与定位

- 提供应用配置和管理的统一入口。
- 管理通知、分类、备份、AI 等子模块。
- 提供数据管理和应用信息查看。

## 用户故事

- **PRD 关联**：#31、#32、#33
- 作为用户，我希望管理通知设置以便控制收到的提醒。
- 作为用户，我希望清除应用数据以便重新开始。
- 作为用户，我希望查看应用信息以便了解版本和详情。

## 交互流程

### 管理通知设置

1. 用户切换 `预算超支提醒` 开关。
2. 关闭时不再触发本地通知（仍可在应用内查看预算警告）。
3. 打开时若未授权通知权限，弹出系统权限申请。
4. 定期交易提醒同理。

### 清除数据

1. 用户点击 `清除数据` → 弹窗确认。
2. 弹窗内容：`确定要清除所有数据吗？此操作不可撤销，建议先备份数据。`
3. 提供 `去备份` 跳转链接。
4. 确认后：
   - Rust 层清空所有表。
   - 重置应用状态。
   - Toast `数据已清除`。
5. **不**自动跳转到欢迎页（避免给老用户造成干扰，但保留空状态引导）。

### 查看应用版本

1. 用户点击 `应用版本` → 弹出底部 Sheet 显示更新日志。
2. 显示当前版本 + 历史版本更新内容。

### 跳转 AI 设置 / 备份 / 分类管理

- 点击对应项 → 跳转到子页面（P-12 / P-13 / P-06）。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 通知权限被永久拒绝 | 开关切换时提示 `请到系统设置中开启通知权限` |
| 清除数据中异常 | 提示 `清除失败，请重试`，不修改数据 |
| 反馈邮件未配置 | 提示 `未配置反馈邮箱` |
| 应用商店未安装 | 跳转应用商店按钮隐藏 |
| 没有更新日志 | 隐藏该项 |

# P-04 交易详情页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-04 |
| 页面名称 | 交易详情页 |
| 所属模块 | 交易模块 |
| 入口 | 首页列表项点击、搜索结果项点击 |
| 出口 | 返回上一页、交易录入页 P-03（编辑模式） |

## 目的与定位

- 展示单笔交易的完整信息。
- 提供编辑、删除等管理操作的入口。
- 保持简洁清晰，聚焦于交易内容本身。

## 用户故事

- **PRD 关联**：#4、#5、#9
- 作为用户，我希望查看某笔交易的完整信息。
- 作为用户，我希望从详情页快速进入编辑模式。
- 作为用户，我希望删除不需要的交易条目。

## 页面元素

### 顶部应用栏

- **左侧**：返回箭头
- **标题**：显示类型 `支出详情` 或 `收入详情`
- **右侧**：`编辑` 文字按钮（点击进入编辑模式 P-03）

### 主信息区

- **金额大字显示**：`¥ 123.45`（48sp，颜色按类型区分）
- **分类图标 + 名称**：圆形图标 + 分类名（如 `🍔 餐饮`）
- **日期时间**：`2026-06-01 12:34`

### 详细信息列表

- **类型**：`支出` / `收入`
- **分类**：`餐饮`（可点击跳转分类详情，未来扩展）
- **金额**：`¥ 123.45`
- **日期**：`2026-06-01`
- **时间**：`12:34`
- **备注**：`午餐 - 麦当劳`（无备注时显示 `无`）
- **创建时间**：`2026-06-01 12:34:56`
- **修改时间**：`2026-06-01 13:00:00`（首次创建后未修改则不显示）
- **AI 分类标记**：若分类由 AI 建议，显示 `🤖 AI 建议分类` 小标签

### 底部操作区

- **删除按钮**：底部固定按钮，文字 `删除交易`（红色）

## 交互流程

1. 用户从首页 / 搜索结果点击某条交易 → 进入交易详情页。
2. 查看完整信息。
3. 点击右上角 `编辑` → 进入交易录入页编辑模式（P-03）。
4. 点击底部 `删除交易` → 弹窗确认 `确定要删除这笔交易吗？此操作不可撤销`。
5. 确认后删除 → 返回上一页并显示 Toast `已删除`。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 交易已被删除（异常进入） | 显示空状态 `交易不存在` 并自动返回 |
| 分类已被删除 | 详情页显示 `已删除分类` 灰色文字，禁止编辑分类 |
| 备注超过 200 字 | 详情页自动换行显示，编辑时仍限制 200 字 |
| 金额为 0 | 不允许保存，但理论上不会出现 |

## 相关模块

- **进入**：首页（P-02）、搜索页（P-05）
- **离开**：交易录入 P-03（编辑模式）、首页 P-02（删除后）

## 验收标准

- [ ] 显示交易的完整信息。
- [ ] 点击 `编辑` 进入编辑模式。
- [ ] 点击 `删除交易` 需二次确认，确认后删除并返回。
- [ ] 分类被删除时显示 `已删除分类`。
- [ ] AI 建议的分类显示 `🤖 AI` 标记。
- [ ] 首次创建后未修改的交易不显示 `修改时间`。

# P-08 预算历史页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-08 |
| 页面名称 | 预算历史页 |
| 所属模块 | 预算管理模块 |
| 入口 | 预算管理页（P-07）`历史` 按钮 |
| 出口 | 返回预算管理页（P-07） |

## 目的与定位

- 展示过去若干个月的预算执行情况。
- 帮助用户回顾预算表现，识别长期消费模式。
- 不可编辑历史预算，仅供查看。

## 用户故事

- **PRD 关联**：#19
- 作为用户，我希望查看过去几个月的预算表现。
- 作为用户，我希望对比不同月份的预算执行情况。

## 页面元素

### 顶部应用栏

- **左侧**：返回箭头
- **标题**：`预算历史`

### 时间筛选

- **时间范围选择**：
  - `最近 3 个月` / `最近 6 个月` / `最近 12 个月` / `全部`
  - 默认 `最近 6 个月`

### 历史列表

- **月度卡片**：
  - 顶部：月份标题（如 `2026 年 5 月`）
  - 总预算进度条 + 已用 / 总额
  - 分类预算简表（仅展示前 3 个分类预算使用率）
  - 超出预算标识（红色徽标 `已超支 ¥XXX`）
- **点击展开**：展开后显示完整分类预算列表
- **排序**：按月份降序

### 空状态

- 历史数据不足时显示 `暂无历史预算数据`

## 交互流程

1. 用户从预算管理页点击 `历史` 按钮 → 进入预算历史页。
2. 默认展示最近 6 个月的预算数据。
3. 切换时间范围 → 列表刷新。
4. 点击某月卡片 → 展开/收起详细分类预算。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 历史月份无预算 | 显示 `未设置预算` 占位 |
| 仅有一个月历史 | 正常展示，无特殊处理 |
| 历史数据为空 | 显示空状态 |
| 时间范围切换 | 列表平滑刷新 |

## 设计要点

- **月度卡片**：白底圆角，阴影轻量，月度间留 12dp 间距。
- **进度条**：与预算管理页一致的色阶规则。
- **展开动画**：高度过渡 250ms ease-out。
- **超出预算徽标**：红色小标签，紧贴金额右侧。

## 相关模块

- **进入**：预算管理页（P-07）
- **离开**：返回预算管理页（P-07）

- [ ] 默认展示最近 6 个月预算数据。
- [ ] 可切换时间范围。

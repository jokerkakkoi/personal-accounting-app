# P-10 趋势图页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-10 |
| 页面名称 | 趋势图页 |
| 所属模块 | 报表分析模块 |
| 入口 | 报表分析页（P-09）`趋势图` 入口 |
| 出口 | 返回报表分析页（P-09） |

## 目的与定位

- 通过折线图直观展示收入和支出随时间变化的趋势。
- 帮助用户识别长期财务模式。
- 支持切换时间粒度（月/季/年）以满足不同分析需求。

## 用户故事

- **PRD 关联**：#22
- 作为用户，我希望查看收入和支出的趋势图。
- 作为用户，我希望识别财务模式。

## 页面元素

### 顶部应用栏

- **左侧**：返回箭头
- **标题**：`收支趋势`

### 时间范围选择

- **分段控制器**：`近 6 个月` / `近 12 个月` / `近 5 年` / `自定义`
- 自定义时弹出日期范围选择器

### 图表区

- **双折线图**（ECharts）：
  - X 轴：时间（月/季/年）
  - Y 轴：金额（自适应）
  - 收入线：绿色
  - 支出线：珊瑚色
  - 数据点：可点击查看该时间点详情
- **图例**：右上角，可点击切换显示

### 汇总数据

- **总收入**：`¥ 12,345.00`
- **总支出**：`¥ 8,765.00`
- **平均月收入** / **平均月支出**
- **最高单月收入** / **最高单月支出**

### 时间点详情（点击数据点展开）

- 该时间点收入金额 + 交易笔数
- 该时间点支出金额 + 交易笔数

## 交互流程

1. 用户从报表分析页点击 `趋势图` 入口 → 进入趋势图页。
2. 默认展示近 6 个月趋势。
3. 切换时间范围 → 图表和汇总数据刷新。
4. 点击图表数据点 → 弹出该时间点详情。
5. 点击 `自定义` → 选择起止日期 → 应用。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 选中时间段无数据 | 图表显示空白 + `暂无数据` |
| 金额差异巨大（极值） | Y 轴使用对数缩放（可选）或自适应 |
| 时间范围过大 | 限制最大 5 年 |
| 仅有一笔交易 | 仅显示一个数据点 |

## 相关模块

- **进入**：报表分析页（P-09）
- **离开**：返回报表分析页（P-09）

## 验收标准

- [ ] 默认展示近 6 个月趋势。
- [ ] 折线图正确渲染收入和支出两条线。
- [ ] 可切换时间范围（近 6/12 月、近 5 年、自定义）。
- [ ] 点击数据点显示该时间点详情。
- [ ] 汇总数据（总收入、总支出、平均、最高）正确计算。
- [ ] 图例可点击切换显示。
- [ ] 无数据时显示空状态。

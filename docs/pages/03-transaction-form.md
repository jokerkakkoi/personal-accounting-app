# P-03 交易录入 / 编辑页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-03 |
| 页面名称 | 交易录入 / 编辑页 |
| 所属模块 | 交易模块 |
| 入口 | 首页 FAB（新增）、交易详情（编辑）、交易搜索（编辑） |
| 出口 | 返回上一页（保存或取消）、交易详情页 P-04（编辑模式） |

## 目的与定位

- 提供统一的表单用于新增和编辑交易记录。
- 集成 AI 智能分类，自动建议分类（异步执行）。
- 支持文字备注、日期选择、金额输入等基础字段。
- 自动保存草稿（每 30 秒），防止意外丢失。

## 用户故事

- **PRD 关联**：#1、#2、#3、#4、#7、#8、#24、#25
- 作为用户，我希望快速记录一笔收入或支出。
- 作为用户，我希望 AI 自动建议分类，以便节省时间。
- 作为用户，我希望添加备注以便日后回溯。
- 作为用户，我希望编辑已有交易以便纠正错误。

- 作为用户，我希望即使误退也能恢复草稿。

## 页面元素

### 顶部应用栏

- **左侧**：返回箭头（取消当前编辑）
- **标题**：动态显示 `记一笔` 或 `编辑交易`
- **右侧**：`保存` 文字按钮（表单有效时可点击，否则置灰）

### 类型切换

- **分段控制器**：`支出` / `收入`
- 默认选中 `支出`，切换时清空金额并刷新分类列表（仅显示对应类型分类）。

### 金额输入区

- **大字号金额显示**：`¥ 0.00`（数字字号 48sp，珊瑚色）
- **数字键盘**：自定义 0-9 数字键盘 + 小数点 + 删除键
- **快捷金额按钮**（可选）：`+10`、`+50`、`+100`

### 分类选择

- **分类网格**：4 列网格展示当前类型的所有分类（图标 + 名称）
- 选中分类显示珊瑚色边框。
- AI 建议时，建议分类右上角显示 `🤖 AI 推荐` 角标。
- 点击 `+ 添加分类` 入口跳转到分类管理页（P-06）。

### 日期与时间

- **日期选择器**：点击弹出日期选择器，默认今天。
- **时间选择器**：点击弹出时间选择器，默认当前时间。
- 重复交易入口：`🔁 设为定期交易`（复选框或独立入口）

### 备注

- **备注输入框**：单行文本框，最多 200 字。
- 占位符：`添加备注（可选）`

### 定期交易折叠区（条件显示）

- 当用户勾选 `设为定期交易` 时展开。
- **重复周期**：`每日` / `每周` / `每月` / `每年`
- **结束条件**：`永不` / `指定日期`
- **下一次执行日期**：自动计算并显示

## 交互流程

### 新增交易

1. 用户从首页 FAB 进入，默认进入"新增"模式。
2. 切换 `支出` / `收入` 类型。
3. 通过数字键盘输入金额。
4. 从分类网格选择分类（AI 在线时显示 AI 推荐角标）。
5. 选择日期和时间（默认今天 / 当前时间）。
6. 可选：填写备注。
7. 点击 `保存` → 写入数据库 → 触发 AI 分类（异步）→ 返回首页。

### 编辑交易

1. 用户从交易详情页进入，表单预填充。
2. 修改字段，点击 `保存` → 更新数据库。
3. 点击返回箭头 → 弹窗 `放弃修改？`（未修改则不弹窗）。

### AI 分类异步流程

1. 用户保存交易后，Rust 层写入数据库。
2. 后台异步调用用户配置的 LLM API（超时 10 秒）。
3. **在线 + 成功**：更新分类为 AI 建议值。
4. **离线 / 超时 / 失败**：保持"未分类"状态，用户可手动修改。
5. 异步过程不阻塞用户操作。

### 草稿自动保存

- 每 30 秒将当前表单内容写入本地草稿。
- 用户意外退出后再次进入录入页，提示 `发现未保存的草稿，是否恢复？`。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 金额为 0 | `保存` 按钮置灰，提示 `请输入金额` |
| 未选择分类 | `保存` 按钮置灰（也可选择"未分类"） |
| 网络断开 | AI 分类降级为"未分类"，不影响其他字段 |
| 用户修改 AI 建议 | 以用户最终选择为准，不再二次覆盖 |
| 删除正在编辑的分类 | 提示用户重新选择分类 |
| 草稿恢复冲突 | 显示对比弹窗，让用户选择保留草稿或新输入 |

# P-09 报表分析页（汇总）

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-09 |
| 页面名称 | 报表分析页（汇总） |
| 所属模块 | 报表分析模块 |
| 入口 | 底部 Tab `报表` |
| 出口 | 趋势图 P-10、分类支出明细 P-11、首页 P-02、设置 P-14 |

## 目的与定位

- 提供每日、每周、每月、每年的收支摘要。
- 作为报表模块的入口页，引导用户深入查看具体图表。
- 单一页内展示关键指标，让用户快速了解财务全貌。

## 用户故事

- **PRD 关联**：#21
- 作为用户，我希望查看每日、每周、每月、每年的收支摘要。

## 页面元素

### 顶部应用栏

- **标题**：`报表`

### 时间维度切换

- **分段控制器**：`日` / `周` / `月` / `年`
- 默认 `月`

### 时间选择器

- 当前选中时间显示 + 左右切换箭头
- 切换粒度随分段控制器变化

### 收支汇总卡片

- **总收入**：`¥ 12,345.00`（绿色）
- **总支出**：`¥ 8,765.00`（珊瑚色）
- **净结余**：`¥ 3,580.00`（深色）
- 与上一周期对比：
  - 收入 `+5.2%`（绿色 ↑）或 `-2.3%`（红色 ↓）
  - 支出 `+8.1%` 或 `-3.4%`
  - 净结余 `+12.0%` 或 `-5.0%`

### 入口卡片

- **趋势图入口**：
  - 缩略折线图（最近 7 天 / 4 周 / 12 月 / 5 年）
  - 标题：`收支趋势`
  - 点击进入趋势图页（P-10）
- **分类支出明细入口**：
  - 缩略饼图（前 5 个分类）
  - 标题：`分类支出占比`
  - 点击进入分类支出明细页（P-11）

### 排行榜（可选）

- **支出 TOP 5 分类**：显示金额最高的 5 个分类及金额
- **收入 TOP 3 来源**（如有意义）：显示金额最高的 3 个收入分类

## 交互流程

1. 用户进入报表页，默认展示当月数据。
2. 切换时间维度（日/周/月/年）→ 数据重新计算。
3. 切换时间（前/后箭头）→ 展示对应时间数据。
4. 点击 `趋势图` 入口 → 进入趋势图页（P-10）。
5. 点击 `分类支出明细` 入口 → 进入分类支出明细页（P-11）。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 选中时间段无数据 | 汇总显示 `¥ 0.00`，入口卡片显示 `暂无数据` |
| 仅有一笔交易 | 正常展示，对比数据为 `—` |
| 时间切换跨年 | 标题年份更新 |
| 时间维度为日 | 显示当日所有交易汇总 |

## 相关模块

- **进入**：底部 Tab
- **离开**：趋势图（P-10）、分类支出明细（P-11）、首页（P-02）、设置（P-14）

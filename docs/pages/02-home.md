# P-02 首页（账单列表）

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-02 |
| 页面名称 | 首页 / 账单列表 |
| 所属模块 | 交易模块 |
| 入口 | 应用启动默认页 / 底部 Tab "首页" |
| 出口 | 交易录入（P-03）、交易详情（P-04）、搜索（P-05）、分类管理（P-06）、预算（P-07）、设置（P-14） |

## 目的与定位

- 作为应用首屏，集中展示用户最近的交易记录。
- 提供快捷入口进入添加交易、搜索、分类管理、预算、设置等核心功能。
- 在首页顶部显示预算超支横幅警告（当用户拒绝通知权限时降级方案）。

## 用户故事

- **PRD 关联**：#1、#2、#3、#6、#9
- 作为用户，我希望快速看到最近的交易记录，以便掌握财务动态。
- 作为用户，我希望在首页直接添加新交易，以便减少操作步骤。
- 作为用户，我希望搜索/筛选交易，以便找到特定记录。
- 作为用户，我希望看到预算超支提醒，以便控制支出。

## 页面元素

### 顶部区域

- **应用栏**：左侧显示当前月份（如 `2026 年 6 月`），右侧显示 `搜索` 图标按钮。
- **月度汇总卡片**（可选展示）：
  - 本月收入：`¥ 12,345.00`（绿色）
  - 本月支出：`¥ 8,765.00`（珊瑚色）
  - 净结余：`¥ 3,580.00`（深色）
- **预算超支横幅**（条件性展示）：
  - 仅在用户拒绝了通知权限时显示。
  - 黄色或红色横幅，文案如 `您有预算即将超支，点击查看 →`。
  - 点击跳转到预算页（P-07）。

### 中部：交易列表

- **日期分组**：按日期降序分组，每组显示日期标题（如 `今天`、`昨天`、`6 月 1 日`）。
- **交易条目**：
  - 左侧：分类图标（圆形背景 + 图标）
  - 中部：分类名称 + 备注（若有）
  - 右侧：金额（支出珊瑚色、收入绿色，顶部对齐）
- **加载规则**：每页 30 条，下拉刷新，上拉加载更多。
- **空状态**：插图 + 文案 `还没有交易，点击 + 添加` + 引导按钮。

### 底部区域

- **悬浮按钮（FAB）**：`+` 图标，珊瑚色，点击进入交易录入页（P-03）。
- **底部 Tab 栏**（4 个 Tab）：
  - `首页`（当前页）
  - `预算`（P-07）
  - `报表`（P-09）
  - `我的`（P-14 设置）

## 交互流程

### 主流程：查看与添加交易

1. 用户进入首页，默认展示当月所有交易，按日期降序分组。
2. 下滑列表触发下拉刷新。
3. 触底自动加载下一页（30 条）。
4. 点击 `+` 按钮 → 进入交易录入页（P-03）。
5. 点击某条交易 → 进入交易详情页（P-04）。
6. 点击顶部搜索图标 → 进入搜索页（P-05）。

### 定期交易触发

- 应用启动时 / 从后台恢复前台时，触发定期交易到期检查。
- 如有到期的定期交易，在列表顶部插入"已自动创建定期交易"提示卡片（轻量 Toast 或顶部条幅）。

### 超支横幅展示

- 进入首页时检查是否存在预算超支（80% 黄色、100% 红色）。
- 用户已拒绝通知权限时，顶部显示横幅警告。
- 点击横幅跳转至预算页（P-07）。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 首次进入（无数据） | 显示空状态插图 + 引导按钮 |
| 列表数据为空但存在预算 | 仍显示顶部汇总卡片 + 空状态列表 |
| 网络断开 | 不影响本地数据展示，仅 AI 分类不可用 |
| 交易数量极大 | 分页加载（每页 30 条），SQLite 索引优化 |
| 用户删除最后一条交易 | 列表切换为空状态，但汇总卡片继续显示 |

## 设计要点

- **货币格式**：`¥ 1,234.50`，2 位小数，千分位逗号分隔。
- **颜色编码**：
  - 支出：珊瑚色（#FF7F50 类）
  - 收入：薄荷绿（#4ECDC4 类）
  - 净结余：深色（#2D3748 类）
- **分组标题**：使用浅灰背景 + 加粗日期，避免视觉过重。
- **FAB 按钮**：右下角悬浮，珊瑚色，直径 56dp，点击有涟漪反馈。
- **底部 Tab**：图标 + 文字，激活态使用珊瑚色。
- **空状态**：插图尺寸 200×200dp 左右，文字字号 16sp，按钮使用次级按钮样式。

## 相关模块

- **进入**：欢迎页（P-01）完成、底部 Tab 点击、应用启动
- **离开**：交易录入（P-03）、交易详情（P-04）、搜索（P-05）、分类管理（P-06）、预算（P-07）、报表（P-09）、设置（P-14）

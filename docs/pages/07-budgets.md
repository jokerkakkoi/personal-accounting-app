# P-07 预算管理页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-07 |
| 页面名称 | 预算管理页 |
| 所属模块 | 预算管理模块 |
| 入口 | 底部 Tab `预算`、首页横幅警告点击 |
| 出口 | 预算历史 P-08、首页 P-02、设置 P-14 |

## 目的与定位

- 提供月度总预算和分类预算的统一管理。
- 实时展示预算执行情况和剩余预算。
- 触发超支提醒（80% 黄色警告，100% 红色警告 + 通知）。
- 支持在月中调整预算，应对变化情况。

## 用户故事

- **PRD 关联**：#15、#16、#17、#18、#20
- 作为用户，我希望设置月度总预算。
- 作为用户，我希望为特定分类设置预算。
- 作为用户，我希望跟踪预算执行情况。
- 作为用户，我希望接近超支时收到通知。
- 作为用户，我希望在月中调整预算。

## 页面元素

### 顶部应用栏

- **左侧**：当前月份（如 `2026 年 6 月`）+ 左右切换箭头
- **右侧**：`历史` 文字按钮（跳转到 P-08）

### 月度总预算卡片

- **标题**：`本月总预算`
- **进度环 / 进度条**：
  - 已用 / 总额
  - 进度条颜色：绿色（<80%）、黄色（80-100%）、红色（>100%）
- **金额信息**：
  - 已用：`¥ 3,500.00`
  - 总额：`¥ 5,000.00`
  - 剩余：`¥ 1,500.00`
- **编辑按钮**：右上角铅笔图标，点击进入编辑模式

### 分类预算列表

- **列表项**：
  - 左侧：分类图标 + 分类名
  - 中部：进度条 + 已用 / 预算
  - 右侧：金额 + 进度百分比
  - 颜色：绿色 / 黄色 / 红色
- **特殊标识**：
  - 即将超支（80-100%）：黄色叹号图标
  - 已超支（>100%）：红色叹号图标
- **添加分类预算**：`+ 添加分类预算` 入口

### 警告区域

- 当用户拒绝通知权限时，列表顶部显示内联警告卡片：
  - `您有 X 个分类即将超支，请注意控制支出`
  - 黄色背景

## 交互流程

### 设置月度总预算

1. 用户点击总预算卡片 → 进入编辑弹窗。
2. 输入预算金额 → 点击 `保存`。
3. 数据库写入当前月份预算。
4. 列表和进度条刷新。

### 设置分类预算

1. 点击 `+ 添加分类预算` → 弹出分类选择器。
2. 选择一个或多个分类。
3. 对每个分类设置预算金额。
4. 点击 `保存`。

### 切换月份

- 顶部左右箭头切换月份。
- 历史月份的预算只读，不可编辑。

### 超支提醒触发

- **80% 警告**：进度条变黄 + 列表项黄色叹号 + 应用内提示。
- **100% 警告**：
  - 进度条变红 + 列表项红色叹号。
  - **若用户已授权通知权限**：触发系统本地通知。
  - **若用户拒绝通知权限**：在首页顶部显示横幅 + 进入预算页时显示警告卡片。

### 通知权限申请流程

- 首次触发超支提醒时弹出系统权限申请对话框。
- **用户授权**：正常显示本地通知。
- **用户拒绝**：降级为应用内提示（横幅 + 警告卡片），不再重复请求。

### 月中调整预算

- 直接编辑当前月预算金额。
- 历史月份的预算不可修改。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 未设置总预算 | 卡片显示 `点击设置预算` 占位文案 |
| 预算金额为 0 | 视为未设置 |
| 分类预算 > 总预算 | 不强制限制，但提示 `分类预算超过总预算，请确认` |
| 切换到未来月份 | 显示空状态 + `未来月份暂不可设置预算` |
| 切换到历史月份 | 预算只读，仅展示 |
| 删除正在预算的分类 | 提示用户先移除该分类的预算 |

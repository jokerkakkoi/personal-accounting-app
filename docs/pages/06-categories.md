# P-06 分类管理页

## 页面信息

| 项目 | 内容 |
| --- | --- |
| 页面 ID | P-06 |
| 页面名称 | 分类管理页 |
| 所属模块 | 分类管理模块 |
| 入口 | 首页 → 设置 → 分类管理 / 交易录入页 `+ 添加分类` |
| 出口 | 返回上一页 |

## 目的与定位

- 提供预定义分类和自定义分类的统一管理界面。
- 允许用户创建、编辑、删除自定义分类。
- 设置默认分类以提升记账效率。

## 用户故事

- **PRD 关联**：#10、#11、#12、#13、#14
- 作为用户，我希望使用预定义分类以便快速记账。
- 作为用户，我希望创建自定义分类以便贴合个人习惯。
- 作为用户，我希望编辑分类名称和图标。
- 作为用户，我希望删除不再使用的分类。
- 作为用户，我希望设置默认分类以节省时间。

## 页面元素

### 顶部应用栏

- **左侧**：返回箭头
- **标题**：`分类管理`
- **右侧**：`+` 图标按钮（添加自定义分类）

### 类型分段

- **分段控制器**：`支出` / `收入`
- 默认展示支出分类，切换时刷新列表

### 分类列表

- **列表项**：
  - 左侧：分类图标（圆形背景 + 图标）
  - 中部：分类名称
  - 右侧：默认分类显示 `默认` 角标
  - 点击进入分类编辑弹窗
  - 长按弹出操作菜单（设为默认、编辑、删除）
- **分组**：可选按 `预定义` / `自定义` 分组显示

### 空状态

- 切换到某类型且无分类时显示空状态（理论上预定义分类至少有数个）

### 分类编辑弹窗

- **图标选择器**：网格展示可选图标（24-32 个）
- **名称输入框**：单行，最多 8 个字符
- **类型**：只读（不可在编辑时切换类型）
- **保存 / 取消按钮**

## 交互流程

### 查看分类

1. 用户进入分类管理页，默认展示 `支出` 类型分类。
2. 切换 `收入` 类型查看收入分类。
3. 分类按 `预定义` / `自定义` 分组。

### 添加自定义分类

1. 点击右上角 `+` 按钮 → 弹出编辑弹窗。
2. 选择图标（必选）。
3. 输入名称（必填，最多 8 字）。
4. 点击 `保存` → 写入数据库 → 列表刷新。
5. 预定义分类不可添加，只能添加自定义分类。

### 编辑分类

1. 点击列表项 → 弹出编辑弹窗。
2. 修改图标或名称。
3. 点击 `保存` → 更新数据库。
4. 预定义分类仅可修改名称（不允许修改图标），不允许删除。

### 设置默认分类

1. 长按列表项 → 弹出操作菜单。
2. 选择 `设为默认` → 标记为默认。
3. 同一类型下只能有一个默认分类。

### 删除分类

1. 长按列表项 → 弹出操作菜单。
2. 选择 `删除` → 弹窗确认 `删除后该分类下的交易将变为"已删除分类"，确定继续？`。
3. 确认后删除。
4. **预定义分类不允许删除**。
5. 存在关联交易时不允许直接删除，需先迁移。

## 边界情况

| 场景 | 处理 |
| --- | --- |
| 删除正在使用的分类 | 弹窗警告，让用户选择迁移到其他分类或强制删除（变为"已删除分类"） |
| 重名分类 | 不允许保存，提示 `该名称已存在` |
| 默认分类被删除 | 自动取消默认标记 |
| 编辑预定义分类 | 仅允许修改名称，不允许修改图标或删除 |
| 名称超长 | 输入框限制 8 字 |
| 图标为空 | 保存按钮置灰 |

## 设计要点

- **列表项**：左侧 48×48dp 圆形图标，右侧 16sp 名称。
- **默认角标**：珊瑚色小标签，紧贴名称右侧。
- **图标库**：内置 32-48 个图标，扁平化风格（食物、交通、居家等）。
- **预定义分类不可删除不可改图标**，让用户感知"系统"与"自定义"的区别。
- **空状态**：通常不会出现，但若出现显示 `暂无自定义分类，点击 + 添加`。

## 文档结构

每篇页面文档采用统一模板，包含以下章节：

| 章节 | 说明 |
| --- | --- |
| 页面信息 | 页面ID、名称、所属模块、入口位置 |
| 目的与定位 | 页面存在的核心价值 |
| 用户故事 | 对应 PRD 中的相关用户故事编号 |
| 页面元素 | 顶部、主体、底部等区域的组件清单 |
| 交互流程 | 主要用户操作链路 |
| 边界情况 | 空状态、异常状态、权限不足等情况 |
| 相关模块 | 与其他页面的跳转关系 |
| 验收标准 | 验收该页面的检查项 |

## 通用约定

- **货币**：人民币（CNY），符号 `¥`，应用内固定单一货币。
- **语言**：仅中文，金额数字使用阿拉伯数字。
- **日期格式**：默认 `YYYY-MM-DD`；时间格式 `HH:mm`。
- **金额显示**：保留 2 位小数，千分位使用半角逗号 `,`。
- **空状态**：所有列表页面在无数据时显示空状态插图 + 引导文案。
- **加载状态**：下拉刷新、上拉加载（每页 30 条）。
- **错误反馈**：Toast 提示 + 必要时二次确认弹窗。
